# Документация проекта

Папка `docs/` хранит проектную документацию (ТЗ, спеки фич, соглашения), которая упрощает
разработку как для людей, так и для ИИ-ассистентов. При реализации фич опирайся на эти
документы как на источник истины по бизнес-логике и текстам сообщений.

## Содержание

| Документ | Описание |
| --- | --- |
| [AUTH.md](AUTH.md) | Аутентификация: регистрация, вход, восстановление пароля, выход, OAuth (UC-1 … UC-5) со всеми основными и альтернативными сценариями |

## Как пользоваться

- **Разработчикам:** перед реализацией формы или флоу сверяйся с соответствующим use case —
  поля, правила валидации, тексты сообщений и редиректы описаны в спеке дословно.
- **ИИ-ассистентам:** ссылайся на конкретный документ и шаг сценария (например,
  `docs/AUTH.md`, UC-1, шаг 5) при генерации или правке кода.

## Соглашения

- Один файл — одна предметная область (фича/домен).
- Тексты сообщений и системных уведомлений приводятся дословно из ТЗ в формате `{ ... }`.
- Документы на русском языке (технические термины и тексты UI — как в ТЗ).
